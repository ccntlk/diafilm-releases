# Diafilm: установщики

Здесь лежат только готовые установщики Diafilm для автообновления.
Кода здесь нет.

Программа сама проверяет этот репозиторий, качает новую версию и ставит её,
когда стример закрывает программу. Каждое обновление подписано: программа
не поставит файл, подпись которого не сошлась.
